# Community conduct

SwapCtx welcomes contributors with different backgrounds and levels of experience.
Participate respectfully in issues, pull requests, discussions and other project
spaces. Explain technical disagreements with evidence and assume good intent.

Expected behavior includes constructive feedback, respect for personal boundaries,
and care with other people's time and private information. Harassment, threats,
discrimination, sexualized attention, impersonation and publication of private
information are unacceptable. Do not post credentials, private project memory or
provider transcripts to illustrate a disagreement.

Maintainers may edit or remove harmful content, close disruptive discussions, or
limit participation. Responses should be proportional to the behavior and its
impact; good-faith technical disagreement alone is not a violation.

Report inappropriate public content using GitHub's reporting tools. For private
concerns, use a private contact method explicitly supplied by a maintainer; none
is currently advertised by this project. Do not post sensitive details publicly
to request help. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

Project maintainer: [rehnx](https://github.com/rehnx). This policy covers project
spaces and representation of the project; it does not claim authority over
unrelated personal activity.
